# frontend-runtime-check 描述

## 干什么用

用于在浏览器中检查前端页面运行状态，包括打开目标路由、观察 console 错误、确认页面是否渲染，并按需要截取根 DOM。

## 什么时候用

- 用户要求“运行时检查”“页面运行报错”“check console errors”“open page route”或“browser validation”。
- 开发服务已经启动，下一步需要验证页面在真实浏览器环境中的表现。
- 场景流程进入 runtime 阶段，需要确认路由、DOM、控制台和基础交互没有明显运行时问题。

## 什么时候不用

- 不用于代码生成、API 设计或静态 lint 检查。
- 不用于开发服务尚未启动或启动失败的情况；这类问题应交给 boot check。
- 不用于后端问题、非浏览器测试或与当前页面无关的泛化调试。
