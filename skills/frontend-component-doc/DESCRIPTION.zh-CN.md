# frontend-component-doc 描述

## 干什么用

用于根据已有前端组件代码生成或更新中文组件文档。文档风格接近组件库官网：先说明组件用途和使用场景，再给导入方式、ASCII 结构原型图、代码演示、API 表格、设计与样式说明、FAQ/注意事项。

## 什么时候用

- 用户指定了组件文件或组件目录，需要给组件补文档。
- 需要从 TypeScript 类型、props、默认值、JSX/模板、样式、demo、story 或测试中整理组件 API。
- 需要让组件文档包含结构示意图，帮助使用者理解组件区域、children/slot、状态区域和相对位置。
- 需要为组件库、业务组件库或项目沉淀可复用 Markdown 文档。

## 什么时候不用

- 不用于编写、重构或修复组件代码。
- 不用于从设计稿或截图生成组件。
- 不用于在没有读取组件源码时凭空写 API 文档。
- 不用于发明源码中不存在的 props、事件、slot、业务字段或请求逻辑。
- 不用于生成页面级 UI spec、接口集成、lint、启动检查或运行时检查。
