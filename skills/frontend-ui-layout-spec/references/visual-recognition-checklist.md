# 视觉识别检查清单

只在页面包含对应模式时执行相关章节。清单用于防遗漏，不得据此虚构截图中不存在的元素、交互、业务逻辑或页面状态。

## 区域与四类事实

- 区域：检查宽高策略、背景、内容范围、边框、内外边距、滚动和相邻区域的横向位置。
- 文字：记录精确可见文案、字号层级、字重、颜色、行高倾向、对齐、换行或截断。
- 图片/资产：记录尺寸倾向、宽高比、裁剪方式、圆角、多图排列、占位状态和未知资产特征。
- 布局：记录尺寸、间距、对齐、排列方向、固定/自适应、滚动和覆盖关系。
- 层级：记录父子嵌套、兄弟顺序、容器与叶子元素、浮层或绝对定位关系。
- 分隔：共享边框或分隔线只归属一个实现位置；分隔线与页面底色露出的分隔带必须区分。

## 表单与选择控件

- 识别单列、双列或混合布局，以及 label 与控件的上下/左右关系。
- 精确记录 label、placeholder、单位、前后缀、必填标记、帮助文字和可见错误文字。
- 区分文本输入、金额/数字输入、日期选择、下拉、单选、多选、开关和级联关系；无法确定时保留中性元素类型并进入 Open Questions。
- 记录操作按钮位于左、右、居中、两端分布或固定底部，以及按钮之间的主次关系。
- 只记录截图可见的禁用、选中、校验或输入状态，不推测表单字段、规则和提交接口。

## 列表、表格与重复内容

- 识别表头、列、行、卡片、分组、摘要、操作区、分页、总数、排序/筛选入口和加载更多区域。
- 记录分页位于左、右或居中，以及总数、页码、页容量等可见部分的排列顺序。
- 逐项检查重复内容中的图片、主副标题、标签、状态、时间、金额、说明文字和操作入口。
- 点击、滑动、长按、重试或刷新只有在存在可见入口、明确手势提示或用户要求时才记录；不得从常见模式直接推断业务交互。

## 图片组、导航与浮层

- 图片组检查数量、比例、间距、裁剪、圆角、叠放、轮播指示和当前项状态。
- 导航、Tabs、步骤条和筛选项检查选中态、未选中态、分隔、滚动和固定位置。
- 弹窗、抽屉、下拉层、气泡和遮罩检查触发前后状态、覆盖范围、标题、关闭入口、操作区和背景遮罩。

## 可见交互线索

- 按钮、链接、输入框、选择控件、开关、分页、返回和关闭入口可按标准控件语义记录 `click/tap`、`input`、`select` 或 `toggle`。
- 滚动条、轮播指示、拖拽手柄、滑动提示或明确手势文案可以作为 `scroll`、`swipe/drag` 的证据。
- 列表行、卡片、图片、状态标签和普通容器不能仅因“通常可点击”就标记点击；没有明确视觉线索或用户要求时写 `unknown` 或 `none`。
- 截图中的按钮只能证明存在操作入口，不能证明具体 API、路由、删除结果、提交结果或权限规则。
- 多图展示交互前后状态时，记录状态变化和对应图片标签；仍不能超出图片证据补充业务结果。

## 页面状态

- 默认/有数据：记录正常内容与主要操作。
- 空态：记录插图或图标、主副文案和可见操作。
- 加载态：记录局部或全页 loading、骨架屏及其替代范围。
- 错误态：记录错误文案、图标、错误区域和可见重试入口。
- 提交中：仅在提交型页面评估按钮 loading、禁用和表单锁定表现。
- 成功/失败：仅在结果型流程评估 Result 页面、Toast、弹窗或原页反馈。
- 未提供视觉证据时只记录状态覆盖问题，不设计具体状态 UI。

## 移动端专项

- 检查安全键盘/数字键盘、下拉刷新、上拉加载、骨架屏、吸顶栏、固定底部操作区和安全区留白。
- 检查横向滑动、轮播、滑动删除和长按提示，但只记录可见或明确要求的交互线索。
- 检查移动端浮层、键盘弹出、底部弹窗和软键盘遮挡可能造成的布局状态；证据不足时进入 Open Questions。

## 边界

- 不选择最终组件库组件，不编造 props、接口字段、请求参数、业务枚举或真实数据。
- 不把常见业务路径当作页面事实；只把可见交互入口和触发语义交给后续组件映射阶段。
- 图标、图片或用途无法确认时保留尺寸、颜色、位置和形态描述，不凭相似页面命名。
