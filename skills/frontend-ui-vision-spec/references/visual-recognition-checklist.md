# 视觉识别检查清单

只执行与当前页面匹配的章节。清单用于防遗漏，不得据此虚构不可见元素、交互、业务逻辑或状态。

## 区域与证据

- 只用 overview/tile-map 确定全局骨架；按 manifest 顺序逐张查看所有未标线 tile 后再完成元素盘点。
- 检查每个 tile 的四条边；元素在边缘被截断时到相邻 tile 复核，并按原图 bbox 合并重复记录。
- 每条图片结论引用真实 evidence 文件；没有实体证据时不得标为 high/medium。
- 检查区域宽高策略、背景、内容范围、边框、内外边距、滚动和相邻位置。
- 检查文字内容、排版层级、字重、颜色、行高倾向、对齐、换行和截断。
- 检查图片/资产的尺寸倾向、比例、裁剪、圆角、多图排列和占位状态。
- 检查布局尺寸、间距、对齐、方向、固定/自适应、滚动和覆盖关系。
- 检查父子嵌套、兄弟顺序、容器/叶子和浮层关系。
- 区分细线、共享边框和页面底色露出的分隔带；共享结构只归属一次。
- 设计稿旁的尺寸标注或说明文字单独作为 `annotation/provided-constraint`，不要录入页面可见元素。

## 表单与选择控件

- 识别单列、双列或混合布局，以及 label 与控件的上下/左右关系。
- 精确记录 label、placeholder、单位、前后缀、必填标记、帮助文字和可见错误文字。
- 区分文本、金额/数字、日期、下拉、单选、多选、开关和级联；无法确定时使用中性类型并提问。
- 记录操作按钮的位置、排列和主次视觉关系。
- 只记录可见禁用、选中、校验或输入状态，不推测字段规则或提交接口。

## 列表、表格与重复内容

- 识别表头、列、行、卡片、分组、摘要、操作区、分页、总数、排序/筛选入口和加载更多区域。
- 记录可见实例数量和所用记录粒度：`all-visible`、`representative` 或 `structure-only`。
- 记录分页位置，以及总数、页码、页容量等可见部分的顺序。
- 逐项检查代表内容中的图片、主副标题、标签、状态、时间、金额、说明和操作入口。
- 仅在状态、样式、内容形态或交互存在实现差异时，为重复实例分配独立永久 ID。
- 仅在存在可见入口、手势提示或明确需求时记录点击、滑动、长按、重试或刷新。

## 图片组、导航与浮层

- 图片组检查数量、比例、间距、裁剪、圆角、叠放、轮播指示和当前项状态。
- 导航、Tabs、步骤条和筛选项检查选中、未选中、hover 残留、分隔、滚动和固定位置。
- 弹窗、抽屉、下拉层、气泡和遮罩检查覆盖范围、标题、关闭入口、操作区和背景遮罩。
- 多输入提供触发前后状态时复用稳定 ID，不推断业务结果。

## 状态与响应式 viewport

- 默认/有数据：记录正常内容和主要入口。
- 空态：记录插图/图标、主副文案和可见操作。
- 加载态：记录局部/全页 loading、骨架屏和替代范围。
- 错误态：记录错误文案、图标、区域和重试入口。
- 提交中：仅在提交型页面评估按钮 loading、禁用和表单锁定。
- 成功/失败：仅在结果型流程评估 Result、Toast、弹窗或原页反馈。
- 比较多个 viewport 时记录区域重排、隐藏/显示、折叠、换行、滚动策略和固定区域变化。
- 未提供视觉证据时只记录覆盖问题，不设计具体状态或响应式 UI。

## 移动端专项

- 检查安全区、数字/软键盘、下拉刷新、上拉加载、骨架屏、吸顶栏和固定底部区域。
- 检查横向滑动、轮播、滑动删除和长按提示，但只记录可见或明确要求的线索。
- 检查浮层、键盘弹出和底部弹窗造成的遮挡；证据不足时进入 Open Questions。

## 边界

- 不选择最终组件库组件，不编造 props、接口字段、请求参数、业务枚举或真实数据。
- 不把常见业务路径当作页面事实。
- 不因“这种页面一般都有”补写未展示的导航、按钮、状态、字段、图标或交互。
- 把可见形态与用途分开；证据只能支持形态时使用中性名称或 `unknown-*`。
- 放大裁剪只能帮助查看已有像素，不能把模糊形状升级为确定文字或业务含义。
- 不主动读取用户未指定的相似业务页面、目录或文件。
- 图标、图片或用途无法确认时保留尺寸、颜色、位置和形态，不凭相似页面命名。
