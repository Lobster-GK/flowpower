# frontend-boot-check 描述

## 干什么用

用于启动或验证前端开发服务，读取并分析启动、编译、构建日志，定位导致项目无法启动或构建失败的问题。

## 什么时候用

- 用户要求“启动检查”“项目启动失败”“run dev server”“start check”或“fix startup error”。
- 场景流程进入 boot 阶段，需要确认生成或修改后的前端项目能正常启动。
- 终端出现编译错误、依赖错误、Vite/Webpack 启动失败、TypeScript 构建错误等启动阶段问题。

## 什么时候不用

- 不用于 UI 生成、接口集成或视觉还原审查。
- 不用于只需要 lint 的静态检查，也不处理已经进入浏览器后的运行时 console 错误。
- 不用于后端服务、部署发布、CI/CD 配置或无关项目初始化。
